# CUTUPP downloads

Installers for **CUTUPP**, first-person highway racing for Windows. Get the game from the official CUTUPP website:
its Download button always serves the newest release from here.

- Windows 10 or 11, 64-bit, DirectX 12 graphics card
- New downloads can trigger Windows SmartScreen: choose **More info**, then **Run anyway**.

## Credits

The cars in CUTUPP are 3D models shared on Sketchfab under Creative Commons licences. Every model was modified for
the game (converted for real-time rendering in Unreal Engine, geometry optimised, materials rebuilt, interior, lamps,
wheels and gauges rigged). The modified versions of the CC BY-NC-SA 4.0 models are shared under that same licence.
CUTUPP is free and non-commercial.
